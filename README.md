## 機能紹介

### 背景・ヘッダー・フォントのカスタマイズ

お気に入りの画像や動画を、POLITEの背景に設定できます。背景を楽しみながら学習しやすいように、明度と透明度、本文の透明度をそれぞれ調整できます。

- **画像・動画背景**：手元のファイルを選択して設定。
- **ヘッダーの配色**：背景色・文字色・枠線色を変更。
- **フォント**：プリセットの書体や、フォント名・URLを指定したカスタムフォントを使用。
- **本文の配置**：左寄せ・中央・右寄せから選択。

### ダークモード

ライト表示から暗い配色へ切り替えられます。「オフ」「常にオン」「自動」を選べるほか、明るさ・コントラスト・グレースケール・セピアも調整できます。設定は次回の表示にも適用されます。

### 週間時間割

ダッシュボードに、自分の履修科目を並べた週間時間割を表示します。科目名からコースへ移動でき、今日の曜日や授業中のコマも見分けられます。

- **科目の検索・配置**：編集画面で候補を選び、曜日と時限に設定。
- **締切の確認**：科目に関連する課題・クイズの締切も表示。
- **保存と引き継ぎ**：時間割をブラウザに保存。書き出し・読み込みにも対応。
- **表示の切り替え**：時間割が不要な場合は、設定から非表示に変更。

### 課題の締切を強調

タイムラインに掲載された締切を、残り時間の表示と色で見つけやすくします。掲載時、残り3日以内、24時間以内・期限超過で強調を切り替えます。

強調色はタイムライン見出し横のパレット、または表示設定から変更できます。締切一覧・時間割・課題一覧の配色に反映されます。

### 課題・クイズの一覧と自動確認

コース内の課題とクイズを一覧にまとめ、ダッシュボードで取得した締切も表示します。広い画面では左側の余白に置き、本文を読みながら確認できます。

「未着手」「作業中」は自分で管理し、提出済み・受験済みはMoodle上で確認できた結果を反映します。完了した項目は控えめに表示し、これから取り組むものを探しやすくします。

### 出席管理

操作履歴を残し、直前の記録の取り消しにも対応しています。大学への出席登録とは別の、個人用の管理機能です。

### 資料参照サイドバー

PDF・TXTを画面右側に開き、コースや課題と並べて読めます。手元のファイルだけでなく、POLITE内のPDFや資料ページのURLにも対応しています。

コース内のPDFリンク横にある「資料参照に追加」から、そのまま資料を開けます。パネルの幅はドラッグで調整でき、前回開いた資料は次回も復元します。

### クイズの解き直し

対応するクイズのレビュー画面に、復習用の「解き直し学習モード」を追加します。問題を解き直して結果を確認でき、Moodleの成績には影響しません。

問題形式やレビューの公開設定によっては対応できない場合があります。

### 洗練UI・拡張レイアウト・コースの目次

コース上部の余白や操作ボタン、カードの見た目を整える洗練UIを、任意で有効にできます。教材一覧では、PDF・課題・クイズなどを種類別のアイコンで表示します。

拡張レイアウトでは、ダッシュボードとマイコースの表示領域を広げて画面を活用できます。コースの目次から授業回へ移動でき、長いページでも目的の場所を探しやすくなります。

## はじめる

### Chromeウェブストアから

1. [Custom-POLITEのストアページ](https://chromewebstore.google.com/detail/plihohicbpnimfimobapbjeebebabjja)を開き、「Chromeに追加」からインストールします。
2. [POLITE](https://polite.do-johodai.ac.jp/)にログインします。既に開いている場合は、ページを再読み込みしてください。
3. 右上の**歯車**から「表示設定」を開き、好みの表示に調整します。
4. 「**変更を保存**」を押すと、次回も設定が適用されます。

対応対象は **PC版Chrome上のPOLITE** です。ほかのMoodleサイトやスマートフォン向けの機能ではありません。

<details>
<summary><strong>開発版を手動で読み込む</strong></summary>

1. リポジトリの「Code → Download ZIP」からダウンロードし、ZIPを展開します。
2. Chromeで `chrome://extensions/` を開きます。
3. 「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. **`manifest.json` が入っている `dist` フォルダ**を選択します。
6. POLITEを再読み込みします。

手動更新では、同じフォルダの内容を新しい版へ差し替え、拡張機能の再読み込みとPOLITEのページ更新を行います。開発版にChromeウェブストアの自動更新は適用されません。

</details>

## 使い方

### 1. 画面を自分に合わせる

1. ページ**右上の歯車**を押して「表示設定」を開きます。
2. 「外観」「背景」などの見出しを押し、使いたい項目を開きます。閉じた見出しでも現在の設定や色を確認できます。
3. 値を調整し、画面下部の「**変更を保存**」を押します。保存せずに閉じる場合は「キャンセル」です。

| 項目 | 設定できること |
| --- | --- |
| 外観 | ダークモードのオフ／常にオン／自動、明るさ・コントラストなど |
| カラー | ヘッダーの背景・文字・枠線の色 |
| 締切の強調色 | 一覧掲載時／3日以内／24時間以内・期限超過の色 |
| 背景 | 手元の画像・動画、背景の透明度と明度 |
| フォント | プリセットやカスタムフォント |
| コンテンツの表示 | 本文の透明度、左・中央・右の配置 |
| レイアウト | 洗練UI、拡張レイアウト、時間割、アニメーションのオン／オフ |

「背景の透明度」と「コンテンツの透明度」は別の設定です。写真やイラストを使う場合は、本文側の透明度も調整すると読みやすくなります。アニメーションは端末の「動きを減らす」設定を優先します。

<details>
<summary><strong>背景・フォント・表示の詳しい設定方法</strong></summary>

- **ダークモード**：「外観 → モード」で「オフ」「常にオン」「システム設定に従う」を選びます。同じグループの明るさ・コントラスト・グレースケール・セピアで調整できます。
- **背景画像・動画**：「背景 → ファイルを選択」から手元のファイルを指定します。種類はファイルから判定されます。背景の透明度と明度を調整し、保存します。
- **本文の透明度・位置**：「コンテンツの表示」でブロックの透明度と、左・中央・右の配置を選びます。
- **ヘッダーの配色**：「カラー」で背景色・文字色・枠線色をそれぞれ指定します。
- **フォント**：「フォント」でプリセットを選択するか、カスタムフォント名・WebフォントURLを入力します。標準の書体へ戻す場合は「Moodle標準」を選び、カスタム指定を空にして保存します。
- **洗練UI・拡張レイアウト**：「レイアウト」で別々にオン・オフを選べます。教材の種類別表示とコースの目次は洗練UI側の機能です。
- **時間割・動き**：「レイアウト」から週間時間割の表示とアニメーションも個別に切り替えられます。
- **初期設定へ戻す**：設定画面の「設定を初期化」を使います。普段の変更を保存せずに戻る場合は「キャンセル」を使ってください。

</details>

### 2. 週間時間割を作る

1. ダッシュボードの週間時間割にある「**編集**」を押します。
2. 曜日・時限に科目名を入力し、候補から科目を選びます。
3. 候補を選ぶと**コースIDが自動入力**されます。曜日・時限を確認して「**保存して適用**」を押します。
4. 週間時間割に戻り、**科目名をクリック**すると、そのコースへ移動します。時間割は授業の入口としても使えます。

<p align="center">
  <a href="assets/readme/hq-timetable-editor.png"><img src="assets/readme/hq-timetable-editor.png" alt="実際の時間割編集画面。科目の検索欄とコースID、保存して適用ボタン。" width="1000"></a>
</p>

「**書き出し**」で時間割を保存し、「**読み込み**」で引き継げます。検索候補が少ない場合は、先にダッシュボードの「コース概要」を「すべて表示」に切り替えてください。候補はPOLITE上で取得できたコースに依存します。

### 3. 締切と課題・クイズを確認する

- **ダッシュボード**：タイムラインに掲載された締切を強調します。見出し横のパレットから色を変更できます。
- **コース画面**：課題・クイズを一覧で表示します。画面幅に余裕がある場合は左側に配置されます。
- **作業状況**：「未着手」「作業中」は自分で切り替えられます。
- **完了状況**：Moodle上で確認できた提出・受験の完了を自動反映します。「更新」から再確認できます。

ダッシュボードで取得した締切も、該当コースの一覧へ反映します。自動確認できない場合は、未確認・確認失敗として表示します。最終的な提出状況は、POLITEの課題・クイズ画面でも確認してください。

**締切の色を変える**：タイムライン見出し横のパレットを押し、「一覧に掲載」「3日以内」「24時間以内・期限超過」の3色を選びます。同じ設定は右上の歯車 →「締切の強調色」からも変更できます。締切が一覧に載った段階から強調し、期限が近づくと表示を切り替えます。

**一覧の使い方**：課題名・クイズ名を押すと対象の活動を開きます。選択欄で「未着手／作業中」を変更すると保存します。「提出済み／受験済み」はMoodleで完了が確認できた場合の表示で、自分で完了に書き換える操作ではありません。「更新」で再確認でき、見出しの「−」で一覧を折りたためます。一覧内のスクロールは本文と分かれています。

### 4. 出席を記録する

コースの「出席管理」で「**出席**」「**遅刻**」「**欠席**」を押すと記録できます。取り消しボタンと操作履歴も利用できます。

歯車から授業の全回数、必要出席率、遅刻の換算回数を設定すると、あと何回休めるかの目安を表示します。

たとえば全16回・必要出席率2/3・遅刻2回で欠席1回として計算する場合は、出席管理の歯車を開いてその値を入力し、設定を保存します。ページ右上の表示設定用の歯車とは別です。「操作履歴」は開閉でき、記録を間違えた場合は取り消しボタンを使えます。出席データの初期化も、このコースごとの設定内にあります。

**この記録は個人用です。大学への出席登録・送信は行いません。** 残り回数の表示は入力した条件に基づく計算であり、大学の公式な出席判定ではありません。

### 5. 資料を横に開く

コース内のPDFリンク横にある「**資料参照に追加**」を押すと、右側の資料参照にPDFを開きます。読み込み後はURL入力欄が閉じ、資料を広く表示します。

ほかにも、右下の**本のボタン**から次の方法で開けます。

| 方法 | 操作 |
| --- | --- |
| 手元のPDF・TXT | 「開く」からファイルを選択 |
| POLITEのPDF・資料ページ | 「URL」からURLを入力し、「表示」 |

PDFリンク横の「資料参照に追加」は、**URLの入力 → PDFの読み込み → 入力欄を閉じる**ところまで行います。URLを貼り直したり、「表示」をもう一度押したりする必要はありません。

資料の左端をドラッグすると幅を変更できます。「閉じる」で本文の表示領域に戻り、右下の本のボタンから再び開けます。URL欄は「URL」で開閉します。開閉状態・幅・前回の資料は次回の表示にも使われます。

前回の資料は次回も復元します。PCの広い画面では本文と資料を並べて表示し、境界をドラッグして資料の幅を調整できます。POLITE内のURLにはログインと閲覧権限が必要です。

### 6. クイズを解き直す

対応するクイズのレビュー画面では、「解き直し学習モード」から復習できます。Moodleに保存される成績は変更しません。

1. POLITEで受験済みクイズの**レビュー画面**を開きます。
2. 上部の「**解き直しモードを開始**」を押します。
3. 対応する問題に回答し、「**採点**」で結果を確認します。正誤・得点・解き直しにかかった時間を表示します。
4. 「**リセット**」で再度練習できます。「×」から終了すると、確認後に元のレビュー画面を再読み込みします。

問題形式やレビュー画面の設定によっては、正しく動作しない場合があります。通常の受験・提出の代わりには利用しないでください。

### 7. 長いコースを目次から移動する

右上の歯車 →「レイアウト → 洗練UI」をオンにして保存すると、コース内に目次を表示します。授業回・章の名前を押すと、その場所へ移動します。閉じている章は開いて表示するので、長いページを先頭から探し直す必要がありません。目次そのものも開閉できます。

教材一覧ではPDF、ファイル、課題、クイズ、フォルダ、URL、ページ、ブックを種類に応じたアイコンで見分けられます。教材を開く操作は、通常どおり教材名のリンクから行います。

## 更新について

ストア版はChromeの自動更新の対象です。ダッシュボードのアナウンスメント内に、インストール中のバージョンと更新情報を表示します。

- **更新が届いているとき**：新しい版を赤字で案内します。
- **更新後**：バージョンが上がったことを検知すると、更新済みの案内を表示します。
- **手動で確認したいとき**：「更新を確認」からChromeに問い合わせます。

更新確認の対象は **Chromeウェブストア版**です。開発版で読み込んでいる場合は、その旨を表示します。配信には時間差があるほか、短時間の連続確認はChrome側で制限されることがあります。更新後はPOLITEも再読み込みしてください。

## データの保存について

設定・時間割・出席記録・課題の作業状況はChromeのローカルストレージ、背景ファイルや参照資料はブラウザ内のIndexedDBへ保存します。この拡張機能独自のクラウド同期はありません。

課題・クイズの完了確認や資料の読み込みには、ログイン中のPOLITEへの通信を使用します。対象サイトは `https://polite.do-johodai.ac.jp/*` です。宣言している権限は [`public/manifest.json`](public/manifest.json) で確認できます。

背景と参照資料は、ブラウザや端末を変えただけでは引き継がれません。時間割は書き出してバックアップできます。ブラウザデータを削除する場合は、保存した情報が失われることがあります。
